# Naria Holidays — Social Media Automation Hub

A premium, modern social media automation platform built with **Next.js (App Router)** and **Tailwind CSS** featuring a clean **White Theme** aesthetic.

---

## 🌟 Features

- **White / Light Theme:** Modern, clean, and airy SaaS design.
- **Two Tabs:**
  - **Image:** Upload image (PNG, JPG, WebP), preview, caption, select target channels, and schedule/publish.
  - **Video:** Upload video (MP4, MOV, WebM), preview with player, caption, select video channels, and schedule/publish.
- **Social Accounts Selection:** Matches the exact multi-channel specification:
  - TikTok
  - Instagram
  - LinkedIn
  - YouTube
  - Facebook
  - X
  - Pinterest
  - Reddit (*Unavailable*)
  - Threads
  - Bluesky
  - Discord
  - Telegram
  - Google Business
- **Unified User Attribution:** User information is displayed once in the header, automatically linking every post to the active signed-in account (`Abir Hasan`).
- **Live Social Media Preview:** Real-time Facebook and Instagram cards syncing instantly with your caption and uploaded media.
- **Post Activity:** Clean history log with status, channels, author, and delete actions.
